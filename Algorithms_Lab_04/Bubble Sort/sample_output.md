# Bubble Sort — Sample Output

The program generates and tests three types of input automatically, so the user only enters the input size.

### Sample Run

```text
Enter number of elements: 1000

Input Size = 1000
Repetitions per measurement = 100

Best Case (sorted input):
CPU Time = 0.00000XXX seconds

Average Case (random input):
CPU Time = 0.00XXXXXX seconds

Worst Case (reverse-sorted input):
CPU Time = 0.00XXXXXX seconds
```

> The CPU-time values above are only an output format example. Actual values must be obtained by running the program.

### Interpretation

The expected order is:

```text
Best Case < Average Case < Worst Case
```

for sufficiently large inputs, although individual measured values can vary because CPU timing is affected by the system.
